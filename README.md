# Travel Survival

말이 잘 통하지 않는 여행지에서 **휴대폰 화면을 보여주고, 상대방이 직접 답을 눌러 의사를 전달할 수 있도록 만든 오프라인 여행 보조 도구**입니다.

현재 **일본어 ↔ 한국어**, **중국어(간체) ↔ 한국어** 버전을 제공합니다.

## 바로 사용하기

- GitHub Pages: https://aicreationeditor-source.github.io/Travel_Survival/
- 일본 여행 카드: `japan_survival.html`
- 중국 여행 카드: `china_survival.html`

## 주요 기능

- 여행 상황별 필수 문장 모음
- 현지어 문장을 큰 화면으로 표시
- 기기 음성 엔진을 이용한 문장 읽어주기
- 상대방이 화면의 선택지를 직접 눌러 답변
- 숫자·시간·금액 등을 크게 적어서 보여주기
- 즐겨찾기 및 최근 사용 문장
- 공항·입국·호텔·교통·택시·식당·쇼핑·결제·관광·병원·긴급 상황 지원
- 중국 여행용 QR 결제, 앱·실명 인증, 관광지 예약 관련 문장
- 긴급 상황용 현지어 카드 및 주요 연락처

## 사용 방법

1. 여행 국가를 선택합니다.
2. 필요한 문장을 검색하거나 상황별 목록을 엽니다.
3. 문장을 누르면 현지어가 큰 화면으로 표시됩니다.
4. 필요한 경우 화면을 상대방에게 보여주세요.
5. 답변 선택지가 있는 화면에서는 상대방이 직접 버튼을 누를 수 있습니다.

말로 설명하기 어려운 상황에서 **“이 화면을 봐주세요”** 하고 바로 건네는 용도를 중심으로 만들었습니다.

## 오프라인 사용

주요 문장, 상황, 선택지는 HTML 파일 안에 포함되어 있어 인터넷 연결 없이 사용할 수 있습니다.

단, 🔊 읽어주기 기능은 기기의 음성 합성 엔진을 사용하므로 해당 언어 음성이 기기에 설치되어 있어야 정상적으로 재생됩니다.

## 개인정보

이 프로젝트는 이름, 전화번호, 숙소 주소 등 개인 식별 정보를 별도로 입력하거나 서버에 전송하도록 설계하지 않았습니다.

브라우저에는 다음과 같은 사용자 설정만 저장될 수 있습니다.

- 즐겨찾기
- 최근 사용 문장
- 화면 테마
- 글자 크기
- 발음 표기 설정
- 읽어주기 속도

이 정보는 현재 사용하는 브라우저의 로컬 저장소에 저장됩니다.

## 주의사항

이 도구는 여행 중 의사소통을 돕기 위한 보조 수단입니다.

- 번역 문장은 모든 상황에서 완벽한 의미 전달을 보장하지 않습니다.
- 의료·법률·안전·긴급 상황에서는 현지 공식 기관과 전문 인력의 안내를 우선하세요.
- 긴급전화, 영사 연락처, 입국·결제·교통 관련 제도는 변경될 수 있으므로 출국 전 최신 정보를 확인하는 것을 권장합니다.
- 일부 기능은 브라우저나 기기 환경에 따라 다르게 동작할 수 있습니다.
