# Travel Survival

말이 잘 통하지 않는 여행지에서 **휴대폰을 작은 키오스크처럼 건네 사용할 수 있도록 만든 오프라인 여행 의사소통 도구**입니다.

일반적인 여행 회화집처럼 문장만 보여주는 것이 아니라,  
**여행자가 질문을 고르고 → 현지인이 화면의 답 버튼을 직접 누르고 → 여행자는 한국어로 답을 확인하는 흐름**을 핵심으로 합니다.

> 번역기를 건네는 대신, 작은 키오스크를 건넵니다.

현재 **일본·중국·미국·싱가포르·호주** 버전을 제공합니다. 미국·싱가포르·호주는 영어 ↔ 한국어 카드이며 각 89개 문장, 8가지 상황을 포함합니다. 국가별 교통·결제 질문과 긴급전화는 별도로 구성했습니다.

## 핵심 컨셉

Travel Survival의 모티브는 **키오스크**입니다.

여행자가 모든 대화를 직접 말하거나 번역 앱에 문장을 계속 입력하는 대신, 필요한 질문을 화면에 띄운 뒤 상대방이 선택지를 직접 누를 수 있게 설계했습니다.

예를 들어:

1. 여행자가 “조식은 몇 시부터인가요?” 같은 질문을 선택합니다.
2. 질문을 현지어로 크게 띄워 상대방에게 보여줍니다.
3. 상대방은 준비된 답변 버튼을 직접 누르거나 필요한 경우 직접 입력합니다.
4. 선택된 답변의 의미가 한국어로 표시됩니다.

즉, **여행자용 탐색 화면**과 **상대방이 직접 조작하는 키오스크형 화면**이 한 기기 안에 같이 들어 있습니다.

## 주요 기능

- 여행 상황별 필수 문장 검색 및 카테고리 탐색
- 공항·입국·호텔·교통·택시·식당·쇼핑·결제·관광·병원·긴급 상황별 흐름
- 현지어 질문을 전체 화면으로 크게 표시
- 상대방이 화면의 선택지를 직접 눌러 답변
- 답변 선택지의 한국어 의미를 여행자 화면에서 함께 확인
- 시간·금액·주소·이름·예약번호·문장 등을 직접 입력해 크게 보여주기
- 기기 음성 엔진을 이용한 현지어 읽어주기
- 최근 사용 문장 및 즐겨찾기
- 자주 쓰는 상황 바로가기
- 긴급 상황용 현지어 카드와 주요 연락처
- 중국 여행용 QR 결제, 앱·실명 인증, 관광지 예약 관련 문장
- PWA 기반 오프라인 사용

## 사용 방법

1. 여행 국가를 선택합니다.
2. 검색, 카테고리, 최근 사용 또는 상황별 바로가기에서 필요한 문장을 찾습니다.
3. 문장을 누르면 현지어가 전체 화면으로 표시됩니다.
4. 화면을 상대방에게 보여줍니다.
5. 답변 버튼이 있는 경우 상대방이 직접 선택합니다.
6. 여행자는 선택된 답변의 한국어 의미를 확인합니다.

말로 설명하기 어려운 상황에서 **“이 화면을 봐주세요” 하고 바로 건네는 것**을 중심으로 설계했습니다.

## 오프라인 사용

이 프로젝트는 PWA 방식의 오프라인 사용을 지원합니다. 처음 인터넷에 연결된 상태에서 페이지를 열면 서비스 워커가 메인 화면, 5개 국가 카드, 웹앱 매니페스트와 아이콘을 기기에 캐시합니다.

화면에 **“✓ 오프라인 사용 준비 완료”**가 표시된 뒤에는 네트워크 연결이 없어도 주요 화면과 문장을 다시 열 수 있습니다.

단, 🔊 읽어주기 기능은 기기의 음성 합성 엔진을 사용하므로 해당 언어 음성이 기기에 설치되어 있어야 정상적으로 재생됩니다.

- 브라우저 확대 제한 제거
- 음성 테스트와 재생 오류 안내
- 긴급 연락처 검수 시점 표시

## 추가 국가 안내

영어권 카드의 발음 표기는 별도로 제공하지 않으며, 읽어주기는 각 국가의 영어 음성 설정을 사용합니다. 즐겨찾기·최근 사용·설정은 나라별로 분리됩니다. 입국·교통·결제 문장은 규정을 단정하는 대신 현장에서 확인하는 질문으로 구성했습니다.

긴급전화 공식 근거 (2026-10-03 확인):

- 미국 911: https://www.usa.gov/crimes-against-children
- 싱가포르 경찰 999 / 소방·구급 995: https://www.gov.sg/contact-us/
- 호주 000: https://www.triplezero.gov.au/

## 개인정보 및 이용 안내

현재 배포본에는 회원가입, 광고·분석 스크립트, 폼 전송 또는 자체 개인정보 수집 서버가 없습니다.

- 이름, 전화번호, 숙소 주소 등 개인 식별 정보를 앱 운영자가 별도로 수집하도록 설계하지 않았습니다.
- '보여주기'나 직접 입력 기능에 적은 내용은 앱에서 저장하지 않습니다.
- 즐겨찾기, 최근 사용 문장, 화면 테마, 글자 크기, 발음 표기, 읽어주기 속도는 현재 기기의 브라우저 로컬 저장소에만 저장됩니다.
- 사이트는 GitHub Pages로 호스팅됩니다. GitHub는 Pages 방문 시 보안 목적으로 방문자의 IP 주소를 기록하고 저장할 수 있다고 안내하고 있습니다.
- 이 도구는 여행 중 의사소통을 돕는 보조 수단입니다. 번역·연락처·입국·결제·교통 등 정보는 상황이나 시점에 따라 달라질 수 있습니다.
- 의료·법률·안전·긴급 상황에서는 현지 공식 기관과 전문 인력의 안내를 우선하세요.
